**Why this happened, stated plainly for next session:** these are long-running (tens of
minutes to multiple hours), unsupervised background compute jobs, launched and monitored by
polling a bash background process across conversation turns. That polling only captures real
elapsed time when the agent is actively in a turn — any gap between turns (including a laptop
going idle/sleeping) passes as pure wall-clock time the process keeps running through, with no
correction. This is a poor way to run anything that takes longer than a few minutes. **Do not
repeat this pattern for the `n=8000` cells.**
