# rather than a naming difference.

# slurm/retry_failed.sh is structurally incompatible with this study, not merely absent.
# The template's retry resumes a flat scratch layout, <root>/<run-id>/, and contains zero
# references to a method level. This study nests per method — submit_per_method.sh:113,
# METHOD_SCRATCH="${SCRATCH_DIR}/${m}" ("per-method subdir: no task-file collision") — so a
# substituted template retry would point one directory level too high, find no task files,
# and resume nothing while exiting 0.
#
# HMS_ID/PROJECT_NAME/STUDY_NAME ARE recoverable from submit_per_method.sh, so this is not a
# missing-values problem. Closing it needs a retry that walks the per-method subdirs, which is
# a change to the template (or a study-local variant), not a copy.
simulations/six-approach-arbitration: slurm/retry_failed.sh
